# NexusPulse frontend

Vite + React + TypeScript + Tailwind CSS v4 + Apache ECharts dashboard for League of Legends timeline analytics.

On Windows PowerShell with script execution disabled, use `npm.cmd` / `npx.cmd` instead of `npm` / `npx`.

## Commands

```powershell
npm.cmd install          # install pinned dependencies
npm.cmd run dev          # dev server on http://127.0.0.1:5173 (proxies /api -> http://127.0.0.1:8000)
npx.cmd tsc --noEmit     # type-check only
npm.cmd run build        # type-check + production build into dist/
npm.cmd run preview      # serve dist/ on http://127.0.0.1:4173
npm.cmd run mock         # regenerate src/mock/*.json (deterministic 32-minute demo game)
```

Start the Python backend on port 8000 first. If it is unreachable, the app shows a banner with **Load demo data**, which loads the bundled mock match.

## Layout

- `src/api.ts` – typed API client (`/api/health`, `/api/matches`, collectors, analysis endpoints)
- `src/types.ts` – types mirroring the backend JSON contract
- `src/components/TimelineChart.tsx` – win probability + power index + stability ribbons in one ECharts instance (two grids, shared minute axis, linked crosshair and dataZoom)
- `src/components/InflectionPanel.tsx` – inflection cards and SHAP decomposition
- `src/components/PlayerPanel.tsx` – radar and anomaly list for the selected player
- `src/components/OverviewStrip.tsx` – scoreboard
- `src/mock/` – demo data, generated by `scripts/generate-mock.mjs`
